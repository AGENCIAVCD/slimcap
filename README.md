# Slimcapilar

Landing page B2B da Slimcapilar para clínicas, revendedores e distribuidores.

## Stack

- Next.js 16 com App Router
- React 19 e TypeScript
- Tailwind CSS 4
- `next/image` e `next/font`
- Google Tag Manager (`GTM-NWPH76JL`)

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Produção

```bash
npm run build
npm start
```

Os CTAs direcionam para o WhatsApp `+55 19 98844-2477` e registram o evento
`clique_whatsapp` no `dataLayer`.
